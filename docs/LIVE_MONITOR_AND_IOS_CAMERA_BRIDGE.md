# 实时监看与 iOS 相机桥接使用说明

> 适用版本：帧澈 ZENCHE 1.5.10 / build 37（W14）
> 状态：1.5.10 / build 37 官网自动更新已生效；厂商相机实测尚待完成。

## 1. 功能说明

五端拍照页均提供“实时监看”开关：

- 开启：启动当前相机的实时取景并显示画面。
- 关闭：停止远程拉帧或相机实时取景，降低相机发热、耗电与网络占用。
- 关闭开关不会断开相机，也不影响拍照；再次开启即可恢复实时画面。

iPhone / iPad 还可以通过同一可信局域网连接 Mac 端相机桥接。桥接支持从 iOS 查看画面、触发拍照并控制实时监看。

## 2. 厂商 SDK 边界

| 相机 | Mac 端控制后端 | iOS 端方式 |
| --- | --- | --- |
| Sony | Sony Camera Remote SDK 2.02.00（官方 SDK） | 连接 Mac 相机桥接，状态明确显示 Sony Camera Remote SDK |
| Nikon | Nikon PTP 兼容控制；Mac 可检测已安装的 Nikon Remote SDK 运行时 | 连接 Mac 相机桥接，状态明确显示 PTP 兼容桥接 |

Sony 与 Nikon 当前公开的桌面 Remote SDK 均不提供可直接嵌入 iOS 的版本。因此 iOS 没有嵌入或改写桌面 SDK；Sony 的官方 SDK 调用发生在 Mac，Nikon 不会被标记成官方 SDK 控制。只有 Nikon 正式提供 iOS SDK 或授权控制接口后，才会切换该标记。

桌面厂商运行时的获取、使用与再分发须遵守各自 SDK 协议及支持机型范围；只有已取得相应许可的用户才应安装和使用厂商运行时。官方入口：[Sony Camera Remote SDK](https://support.d-imaging.sony.co.jp/app/sdk/l/index.php)、[Nikon SDK](https://sdk.nikonimaging.com/information/en/)。

## 3. 在 Mac 上准备桥接

1. 安装并打开 macOS 版帧澈 ZENCHE。
2. 在“连接管理”中连接相机：
   - Sony：选择“索尼官方 SDK”，刷新设备后连接。
   - Nikon：通过 USB / PTP 连接；当前为 PTP 兼容路径。
3. 打开“无线传输”，点击“开启无线接收”。
4. 记下页面显示的 Mac 局域网地址、HTTP 端口 `8080` 和“本次配对码”。
5. 保持 Mac 与 iPhone / iPad 位于同一可信局域网，并允许 macOS 接受帧澈的传入网络连接。

本次配对码为 12 位，每次启动 Mac 版应用都会重新生成。它不会写入磁盘；请勿在公共网络或不可信 Wi-Fi 中使用桥接。

## 4. 在 iPhone / iPad 上连接

1. 打开 iOS 版帧澈 ZENCHE，登录后进入拍照页。
2. 打开“连接管理”，找到“Mac 相机桥接”。
3. 输入 Mac 的局域网 IP（例如 `192.168.1.20`）或 `.local` 主机名。
4. 端口保持 `8080`，输入 Mac 端显示的 12 位本次配对码。
5. 点击“连接 Mac 相机桥接”。连接成功后返回拍照页。
6. 使用“实时监看”开关控制画面拉取；使用拍照按钮触发 Mac 所连相机快门。

iOS 仅接受 `10.x`、`172.16–31.x`、`192.168.x`、`169.254.x`、`localhost` 或 `.local` 地址。主机与端口会保存在本机以便下次填写，配对码不会保存。

## 5. 五端开关位置

- iOS / iPadOS：拍照页画面下方；全屏拍照和视频监看会同步遵循开关状态。
- Android：拍照页实时画面下方。
- HarmonyOS：拍照页实时画面下方。
- macOS：拍照控制页预览区下方。
- Windows：拍照页预览说明栏右侧。

开关只控制实时监看，不会执行“断开相机”。设备断开、退出登录或会话失效仍使用各端原有的统一清理流程。

## 6. 常见问题

### iOS 提示“仅支持可信局域网地址”

请填写 Mac 的内网地址，不要填写公网 IP、带路径的 URL 或代理地址。确认两台设备位于同一可信局域网。

### iOS 提示配对码无效

确认输入的是 Mac 当前页面显示的 12 位本次配对码。Mac 应用重启后旧码立即失效。

### 已连接但没有画面

先确认 Mac 端已连接相机并能在本机看到实时取景，再开启 iOS 拍照页的“实时监看”。相机不支持实时取景、处于菜单/回放状态、USB 模式错误或被其他软件占用时，也可能没有画面。

### 关闭实时监看后还能拍照吗

可以。关闭只停止取景帧，不会断开相机；本机摄像头、Wi-Fi/PTP 和 Mac 桥接的拍照路径仍保留。
