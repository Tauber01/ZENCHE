# 桌面工作区与登录操作说明

> 适用版本：1.5.11 及后续版本；桌面工作区自 1.5.11 引入，1.5.12 / build 39 仅同步版本与启动公告
> 适用平台：登录说明覆盖五端；工作区布局覆盖 macOS 与 Windows
> 公开版本：官网自动更新仍为 1.5.10 / build 37

## 1. 登录

登录页顶部的两个选项用于切换表单，不会直接发送请求：

- **已有账号**：输入邮箱和密码后，点击表单底部的**登录**。
- **创建账号**：填写注册信息后，点击表单底部的**注册**。

提交期间按钮会显示“正在登录…”或“正在注册…”。如果出现错误，先保留页面提示，再检查网络、邮箱格式和密码；不需要反复点击顶部模式选项。

## 2. 调整主窗口

macOS 与 Windows 都可以使用系统窗口边缘调整大小，也会在退出后保存主窗口大小和位置。Windows 还会恢复最大化状态。

如果保存的位置不再属于当前显示器可见区域，应用下次启动时会把窗口移回可见桌面。Windows 多显示器、不同 DPI 缩放和显示器热插拔仍需在真实 Windows 设备上继续验收。

## 3. 调整面板

把指针移到面板边界，出现可调整区域后拖动：

- 主导航与内容区之间；
- 拍摄页预览与参数区之间；
- 编辑页媒体池、中央预览和工具面板之间；
- 编辑页中央预览与底部工具区之间。
- Windows AI 工具页的预览与选项面板之间。

拖动过程中内容会跟随指针实时、连续重排，不需要松开鼠标后才生效。macOS 分隔条悬停或拖动时会显示强调色和系统调整光标；获得键盘焦点后可用方向键按 8 点步进调整。Windows 使用原生 WPF 分隔条，可用系统辅助功能读取其名称。所有宽度和高度都有安全上下限，窗口变窄时会联动收紧外层侧栏与内层面板，优先保留拍摄或编辑中央画面。

macOS 的 AI 工具区不再重复显示完整调整分类，也不会叠加与 AI 生成无关的通用编辑底栏；AI 模式、提示词、组合预设、比例和分辨率因此获得更大的默认可用高度。Windows 的 AI 模式按钮会随面板宽度均分，快捷预设按分类换行；在紧凑窗口中，AI 预览及其分隔条会暂时收起，让选项面板占满可用宽度，窗口放宽后会自动恢复预览和原有可调宽度。

编辑器菜单分为两级：一级“编辑模式”只切换“专业显影 / AI 工具”，二级“调整类别”只列出光线、色彩、色轮、曲线、取色器、蒙版、细节、效果和几何。AI 工具不会再同时出现在两级菜单里；从 AI 工具返回专业显影时会回到上次使用的调整类别。

专业显影底部的 RGB 示波器会占满自身分区的剩余宽度和高度，标题、状态与数值集中在上方，不再用固定宽度把曲线压缩到角落。拖动底部分隔条时，示波器会跟随区域连续伸缩。

为减少调整参数时的卡顿，预览和示波器共用同一份受控尺寸图像，保存与导出才使用完整分辨率。Windows 会把短时间内连续到达的预览刷新合并为一次，停止录制后停止时间码刷新，并在离开编辑页或关闭窗口时释放预览、AI 结果与示波器位图。静态与编译门禁不能替代真实设备上的长时间拖动、内存峰值和帧率测试。

## 4. 使用布局预设

打开**设置 → 桌面工作区**，选择预设：

| 预设 | 适用场景 |
| --- | --- |
| 默认 | 日常拍摄、浏览和编辑的均衡布局 |
| 拍摄 | 扩大拍摄参数区与主窗口 |
| 监看 | 优先保留中央监看画面 |
| 编辑 | 扩大媒体池、工具面板和底部工具区 |
| 紧凑 | 用于较小桌面或临时并排窗口 |

选择预设会立即更新面板尺寸和主窗口大小。之后仍可继续拖动，新的尺寸会自动保存。点击**恢复默认布局**可回到默认预设。

## 5. 当前边界

本版实现的是单主窗口内的可调分区，不是 Adobe 完整的浮动与停靠系统。暂不支持：

- 把任意面板拖成独立浮动窗口；
- 跨窗口或跨显示器停靠面板；
- 自由编组、标签化面板堆栈；
- 导入、导出或命名多个自定义布局。

这些能力需要单独设计面板生命周期、焦点、无障碍、显示器迁移与旧状态升级规则，后续可在现有状态模型上继续扩展。

## 6. 重置与故障排查

1. 面板尺寸不合适：先在设置中点击**恢复默认布局**。
2. 窗口仍不可见：关闭应用后重新打开；恢复逻辑会重新约束窗口位置。
3. 登录仍无反应：确认点击的是表单底部的**登录**，而不是顶部已选中的**已有账号**。
4. 需要反馈时，请附平台、系统版本、显示器数量、缩放比例、操作前后的窗口状态和可复现步骤；不要上传密码、会话令牌或完整设备码。
