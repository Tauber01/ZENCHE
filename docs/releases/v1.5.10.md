## 本次更新

- iPhone / iPad 新增可信局域网相机桥接，可查看 Mac 端所连相机的实时画面并触发拍照。
- Sony 相机由 Mac 端 Sony Camera Remote SDK 驱动；iOS / iPadOS 只连接桥接服务，不嵌入桌面 SDK。
- Nikon 当前走明确标注的 PTP 兼容桥接，不宣称使用 Nikon 官方 iOS SDK。
- iOS / iPadOS、Android、HarmonyOS、macOS、Windows 的拍照页均新增“实时监看”开关。关闭后停止取景帧并清除缓存画面，但不掉相机连接，也不影响快门。
- 官网更新通道改用自托管 `release.json`，返回各平台完整安装包地址和 SHA-256；客户端仍交由操作系统处理安装，不会静默覆盖应用。

## 更新与安装

1. 应用启用“启动时自动检查更新”后，会请求 `https://zenche.top/api/update`；1.5.9 及更早版本现在会看到 1.5.10，1.5.10 不会重复提示。
2. 下载前可将接口返回的 `sha256` 与文件计算结果比对。
3. Android APK 使用现有 Debug 证书，可覆盖同证书构建；若设备上的旧包证书不同，需先备份数据再处理签名冲突。
4. macOS DMG 未公证，首次打开可能被 Gatekeeper 阻止；仅在确认 SHA-256 和来源后使用。
5. Windows 安装器未做 Authenticode，SmartScreen 可能提示未知发布者。
6. iOS / iPadOS IPA 与 HarmonyOS HAP 未签名，官网只能提供下载，不能绕过平台签名要求直接安装。

## 使用与能力边界

完整操作步骤见 `docs/LIVE_MONITOR_AND_IOS_CAMERA_BRIDGE.md`。关闭实时监看只停止画面拉取；相机连接、拍照和文件接收仍沿用原路径。

当前没有兼容的 Sony / Nikon 真机用于本轮验收，因此实时取景、快门、断线恢复、弱网延迟、长时间发热与耗电仍需按机型实测。注册表覆盖或静态测试不等于硬件兼容性证明。
