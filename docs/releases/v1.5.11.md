## 本次变更

- 五端登录页把表单模式改为“已有账号 / 创建账号”，与真正的“登录 / 注册”提交按钮明确区分。
- Apple 登录按钮在请求期间保留动作文字和进度指示，中英日忙碌态使用完整 exact key；切换模式会清除旧错误并把焦点移回邮箱。
- macOS 与 Windows 新增可保存的桌面工作区：恢复主窗口大小和位置，Windows 另恢复最大化状态。
- 主导航、拍摄参数、编辑媒体池、工具面板与底部工具区支持拖动调整；设置页提供默认、拍摄、监看、编辑、紧凑五套预设及恢复默认。
- macOS 与 Windows 分隔条改为拖动中实时连续重排并扩大安全尺寸范围；Windows AI 选项面板新增独立宽度分隔条。
- macOS AI 工具区移除重复的完整分类导航和无关通用编辑底栏；Windows AI 模式按钮与分组预设按可用宽度自适应。
- 窗口变窄时，外层侧栏与内层面板会联动收紧；Windows AI 页在紧凑宽度优先显示完整选项，临时收起预览及其分隔条，窗口恢复后自动还原。
- macOS 与 Windows 将“专业显影 / AI 工具”固定为一级编辑模式，把色轮、曲线、蒙版等收进二级“调整类别”，消除重复入口和层级混用。
- 桌面 RGB 示波器改为填满底部可用区域；预览与示波器复用受控尺寸图像，Windows 另合并高频刷新、按录制状态启停时间码并在离开编辑页时释放位图。
- Windows AI 临时结果只允许在系统临时目录、且文件名严格匹配 `zenche_ai_*.jpg` 时删除；新结果替换、切换照片或模式、离开编辑页和关闭窗口均执行容错清理，用户保存的正式副本不受影响。
- 保存的窗口离开当前显示器工作区时会被约束回可见区域。
- Android 在 Nikon Z50 的 SDRAM 拍摄后下载遇到 `DeviceBusy (0x2009)` 时执行最长 20 秒的有界退避，不再次触发快门；本机摄像头若被厂商 Camera2 HAL 拒绝双 JPEG 会话，则按设备声明能力降级到低负载或共享单流方案。
- 五端默认 AI 地址迁移到账号与设备激活共用的 HTTPS 代理；Android、iOS/iPadOS 与 HarmonyOS 在专业显影和 AI 修图中提供可见的系统照片入口。导入、专业调整和 AI 修图都使用新的应用副本，导出新建系统相册项目，不覆盖系统原片。
- 五端公告不再把全部包笼统称为“未签名”，改为说明各平台签名状态不同并引导查阅逐包说明；下表分别披露 Debug、unsigned、ad-hoc 或无 Authenticode 状态。

## 安装与能力边界

- Android 使用开发环境 Debug 证书；如果设备上旧包证书不同，不能直接覆盖安装。
- iOS / iPadOS IPA 与 HarmonyOS HAP 未签名，需要各平台有效证书和描述文件/Profile。
- macOS 为 ad-hoc 签名且未公证，Gatekeeper 可能阻止首次打开。
- Windows 没有 Authenticode，SmartScreen 可能提示未知发布者。
- Nikon Z50 的对象读取恢复、OPPO Camera2 降级、Android/iOS/HarmonyOS 系统照片导入与另存、权限拒绝恢复、iCloud 下载和真实 AI 代理调用仍需对应平台真机验收。
- 本版本不包含任意浮动面板、跨窗口拖放、跨显示器面板停靠或自定义布局导入/导出。Windows 多显示器/DPI、两端真实拖拽与重启恢复仍需真实桌面环境验收。
- 生产官网更新仍为 1.5.10 / build 37；本地候选不会由自动更新推送给现有用户。

操作方法见 `docs/DESKTOP_WORKSPACE_LAYOUT.md`。
