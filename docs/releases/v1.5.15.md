## 本次更新

### 官网 SEO

- 官网首页增加唯一 self-canonical `https://zenche.top/`，Open Graph 与 Twitter
  预览图改为绝对 URL。
- 增加 `SoftwareApplication` JSON-LD，明确中英语言、作者、项目地址、当前公开
  `1.5.14` 下载、50 款相机档案以及仍在进行的真机验证边界。
- 增加可直接抓取的 `robots.txt` 和 `sitemap.xml`。sitemap 只列根 URL，不把与根
  canonical 共用同一 SPA shell 的 `/redeem` 作为独立规范页，也不虚构独立语言 URL。
- 新增源码和构建产物双重 SEO 校验，锁定 canonical、JSON-LD、爬虫文件、六个公开
  1.5.14 包的名称/字节数以及 Sony 16 款、总档案 50 款等事实。

### Wi-Fi / PTP-IP 稳定性

- Android 在异步网络回调前同步扫描可用网络，选择实际相机 Wi-Fi，并使用同一
  `Network.getSocketFactory()` 创建 command/event 两条 socket；`onLost` 只作用于
  当前会话绑定的网络。该纯绑定方案不需要新增 `CHANGE_NETWORK_STATE` 权限。
- HarmonyOS 通过相机 IPv4 子网选择 API 12 `NetHandle`，在 connect 前绑定两条
  `TCPSocket`，并按 `netId` 过滤网络回调；真实 Probe 完成后才发布就绪，event reader
  空闲接收超时不再被当作断线，回到前台时立即补一次心跳。
- Apple 共享连接层不再把 `NWConnection.waiting` 直接当作失败；Wi-Fi 重关联可在既有
  12 秒握手 deadline 内恢复，取消和终局失败仍有明确裁决。iOS 回到前台时立即进行一次
  idle-safe Probe。
- Windows 增加接口地址变化监听并合并突发事件为一次即时 Probe，阻止心跳 tick 重入，
  将 12 秒握手预算与握手后的 30 秒会话恢复预算分离，并用完整会话代际统一门禁拍摄、
  取景、录像、参数和相机存储操作。
- Android、Apple、Windows 的回归测试直接编译生产传输实现并驱动本地伪相机，覆盖完整
  握手/操作、Probe 丢包、event 半开、静默握手取消/deadline、双 socket 工厂注入与旧
  代际不得拆除活会话；HarmonyOS 由 API 12 构建和六项强化契约覆盖。

## 安装与升级边界

- Android APK 使用项目连续的 Debug 证书；只有证书一致的既有安装才能原位升级。
- iOS/iPadOS IPA 与 HarmonyOS HAP 未签名，只适用于具备自行签名与安装条件的测试环境。
- macOS 应用为 Apple Silicon arm64、ad-hoc 签名且未公证，首次运行可能需要按系统安全
  提示手动确认。
- Windows Setup 与便携包没有 Authenticode；当前包由 macOS 交叉构建，尚未在真实
  Windows 主机运行 `scripts/build-windows.ps1`，也未完成安装、升级、卸载、驱动、
  `NetworkAddressChanged` 或 SmartScreen 验收。
- 本版仅发布到 GitHub；官网正式更新清单没有切换，仍为 `1.5.14 / build 41`，官网
  SEO 也没有部署生产。GitHub Latest 不改变任何安装包的签名、主机或实机属性。
