# 帧澈 ZENCHE v1.5.0

帧澈 ZENCHE v1.5.0 新增五端原生外录能力，版本号为 `1.5.0`，原生构建号为
`25`。本版本继续保留升级、签名、偏好设置和历史素材库所需的 `NikonLink` 与
`com.tauber.nikonlink` 内部标识。

## 版本亮点

- 新增 107 款 Nikon NP3 云创预设：可在原生编辑器以及照片、视频监看画面中进行设备端 SDR 近似预览，效果只作用于显示链路，不写入拍摄原片或外录文件。
- 优化尼康云创监看卡片的颜色、信息层级与窄屏布局；iOS / iPadOS、Android、macOS 与 Windows 使用可搜索或有界的原生弹窗/下拉选择器，HarmonyOS 使用系统 Select，避免重复弹窗和失控尺寸。
- 新增“外录到当前智能设备”：连接相机后，可将实时取景视频流式写入手机、平板或电脑硬盘上的 ZENCHE 文件库。
- 新增“相机机内存储”：五端文件页可浏览存储卷与照片/视频，查看缩略图、大小、拍摄时间和保护状态，批量下载到 ZENCHE，或确认后从相机永久删除。
- 修复标准 PTP 文件枚举：从存储卡根关联开始递归读取 `DCIM` 及其子目录，并对重复或循环对象句柄去重，避免已插卡且有素材时仍显示空列表。
- 修复 macOS 文件列表解析：机内存储枚举保留 gphoto2 的详细输出，正确读取目录内文件序号、大小与删除权限，不再把纯路径输出误判为空列表。
- PTP 相机支持机身存储卡录制与智能设备外录并行；照片继续直接保存到当前设备。
- Android、HarmonyOS、macOS 与 Windows 新增流式 Motion-JPEG AVI 封装器，不把整段视频保存在内存中。
- iOS / iPadOS 本机相机和兼容 UVC 视频源继续通过 AVFoundation 外录为 MOV，并以移动文件方式直接纳入项目会话。
- 外录视频接入会话命名、双目标备份、XMP 旁车和 SHA-256 清单；停止录制、相机断开或写入异常时会尽力安全封装已写入的帧。

## 五端变化

- **iOS / iPadOS**：照片与视频监看接入云创显示链路和可搜索原生 Sheet；监看输出明确显示设备外录状态；本机与 UVC 视频以 MOV 写入 ZENCHE 文件库；大文件 SHA-256 改为分块读取；Wi‑Fi PTP/IP 相机新增机内存储管理。
- **Android**：照片与视频监看接入云创显示链路，预设弹窗限制尺寸、阻止重复叠加并采用“应用”确认；新增持久化外录开关、PTP/本机摄像头外录、MJPEG AVI 流式封装、断开安全收尾、AVI 媒体库分类与分享，以及 USB/PTP 和 PTP/IP 机内存储管理。
- **HarmonyOS**：照片与视频监看接入云创显示链路和系统 Select；ArkUI 监看页新增持久化外录开关；PTP 实时取景写入 MJPEG AVI；媒体库识别 AVI，视频校验改为 1 MiB 分块计算；USB/PTP 和 PTP/IP 接入机内存储管理。
- **macOS**：照片与视频监看接入云创显示链路和可搜索原生 Sheet；SwiftUI 监看页新增外录开关；USB/PTP 与本机摄像头可外录；AVI 纳入视频分类，断开连接时安全完成封装；标准 USB/PTP 与 PTP/IP 连接可浏览和管理相机存储卡，并修复静默文件列表无法解析的问题。
- **Windows**：照片与视频监看接入云创显示链路，预设下拉限制高度并启用虚拟化；WPF 监看页新增持久化外录开关；USB/PTP 与本机摄像头可外录；AVI 纳入文件库和视频分类；USB/PTP 与 PTP/IP 接入机内存储管理；生成 Setup 安装版与便携版。

## 相机与兼容性变化

本版本不改变现有 20 款 Nikon、12 款 Sony α 和 10 款 Canon EOS R 相机档案。
能否同时启动机身录制取决于相机型号、固件、当前拍摄模式和 PTP 能力；即使机身拒绝
远程视频录制，只要实时取景仍可用，应用也会继续设备端外录。iOS / iPadOS 的公开 API
仍不提供 Nikon 厂商 USB/PTP 控制，因此 Apple 移动端通过 Wi‑Fi PTP/IP 管理机内存储；
Android、HarmonyOS、macOS 与 Windows 还可使用标准 USB/PTP。系统相机和 UVC 输入不提供
机内存储。Sony 官方 SDK 会话不开放对象枚举时，应用会提示改用标准 USB/PTP 或 PTP/IP。

## 包与签名状态

- Android APK 使用调试证书签名，可用于侧载验证，不是商店发布签名。
- HarmonyOS HAP 未配置开发者签名与 Profile，真机安装前必须重新签名。
- iOS / iPadOS IPA 为未签名验证包，必须使用有效证书和 provisioning profile 重新签名。
- macOS DMG 内应用采用 ad-hoc 签名并通过 `codesign --verify --deep --strict`，尚未公证。
- Windows Setup 与便携 ZIP 未使用商业代码签名证书，SmartScreen 可能显示警告。

## 已知限制

- 标准 PTP 实时取景不携带音频轨，因此 Android、HarmonyOS、macOS 与 Windows 的 PTP 外录为无声 Motion-JPEG AVI；应用不会伪造音频。
- 外录画质和帧率受相机实时取景 JPEG 分辨率、USB/Wi‑Fi 吞吐、智能设备硬盘写入速度及监看帧率上限影响，不等同于机身原始视频规格。
- 停止或断开时只能封装已经成功接收并写入的帧；设备突然断电、进程被系统强制终止或存储介质物理移除仍可能造成未完成文件。
- 五端相机真机矩阵仍在扩大，重要拍摄必须保留机身存储卡作为独立备份。
- 从相机删除会永久修改存储卡且无法由 ZENCHE 恢复；受保护文件不会进入删除选择。
- 当前对象下载由各端在操作期间持有文件数据，超大视频受平台可用内存和 PTP/IP 对象大小保护上限约束。

## 升级说明

升级前建议备份现有 ZENCHE 文件库和会话目录。Windows 安装版可覆盖安装，便携版应完整
解压并保持 `libusb-1.0.dll`、Nikon SDK 与 Sony SDK 目录结构不变。Android 可侧载覆盖；
iOS / iPadOS 和 HarmonyOS 需按各自平台重新签名。首次进入视频监看页时请确认“外录到
当前智能设备”开关和目标磁盘剩余空间，再进行正式拍摄。
