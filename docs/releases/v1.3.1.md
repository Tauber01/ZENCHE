# 帧澈 ZENCHE v1.3.1

帧澈 ZENCHE v1.3.1 是一次面向 AI 修图工作流和发布信息准确性的同步更新。iOS /
iPadOS、Android、HarmonyOS、macOS 与 Windows 五个原生目标保持同一套功能语义，
同时继续保留 Nikon、Sony、Canon 相机档案与原有拍摄、传输、图库和专业显影能力。

## 版本亮点

- **AI 编辑入口更清晰**：编辑页在移动端默认进入“专业显影”，用户可以通过明确的
  “专业显影 / AI 工具”切换进入 AI 修图或 AI 生图，不再通过重复点击导航栏改变模式。
- **设备码系统恢复**：AI 工具继续显示当前设备 ID，支持复制、激活码输入和验签；激活
  密钥绑定当前设备，AI 云服务次数由服务器计数，客户端不内置模型 API Key。
- **官网兑换入口**：复制设备 ID 后，使用应用内按钮打开
  `https://zenche.top`，兑换绑定当前设备的激活密钥。
- **爱发电购买提示**：AI 激活卡和更新公告加入“在爱发电购买兑换码”提示、二维码和
  购买按钮；二维码和按钮均指向应用内配置的爱发电入口。
- **设置页收敛**：删除可编辑的“AI 服务器”输入窗口和保存控件，降低误配置风险；旧版
  `aiServerURL`、`ai_server_url` 等历史配置仍可读取，升级不会丢失兼容性。
- **相机适配保持**：Nikon 20 款档案、Sony 12 款档案和 Canon EOS R 10 款档案及对应
  vendor/PTP 逻辑继续保留。本版本没有删除相机适配或原有 AI 修图、生图功能。

## 五端变化

- **iOS / iPadOS**：SwiftUI 启动公告与 AI 激活卡同步更新；交付为 unsigned IPA，安装前
  需要使用有效 Team、证书和 Profile 重新签名。
- **Android**：Android Views 启动公告、设备码复制提示、官网跳转和爱发电二维码同步更新；
  交付 APK 使用调试证书签名，需要允许侧载。
- **HarmonyOS**：ArkUI 启动公告、本地化文案和版本诊断信息同步更新；HAP 是否可直接安装
  取决于开发者签名与 Profile。
- **macOS**：SwiftUI 更新公告和版本元数据同步更新；交付 Apple Silicon、ad-hoc、未公证
  DMG。
- **Windows**：WPF 公告、版本元数据和安装器版本同步更新；交付 x64 NSIS 安装器及便携
  ZIP，未使用商业代码签名证书。

## AI 激活与兑换流程

1. 在编辑器打开“AI 工具”，复制页面显示的设备 ID。
2. 点击“前往官网兑换密钥”，或在浏览器打开 `https://zenche.top`。
3. 按官网流程使用兑换码，获取绑定当前设备的激活密钥。
4. 返回应用，在 AI 激活卡中输入激活密钥并验证。
5. 没有兑换码时，点击“在爱发电购买兑换码”或扫描公告中的二维码。兑换码仅用于 AI
   云服务次数，帧澈 ZENCHE 本体仍保持免费开源。

请只使用 `zenche.top` 和应用内爱发电入口。任何要求通过非官方群组购买软件、提供 API
Key 或转账解锁帧澈本体的说法都不属于官方渠道。

## 相机兼容性

- Nikon：EXPEED 5 / 6 / 7 共 20 款已注册机型；macOS、Android、HarmonyOS、Windows
  继续使用原生 USB/PTP 路径。
- Sony：12 款 Sony α 档案与 vendor 识别逻辑保留，仍属于实验性适配，需结合具体固件、
  镜头和主机继续实机验收。
- Canon：10 款 Canon EOS R 档案与 PTP vendor ops 保留，仍属于实验性适配，需继续实机
  验收。
- iOS / iPadOS 受 Apple 公开 API 限制，不宣称提供 Nikon 厂商 USB/PTP 控制；系统相机、
  兼容 UVC 输入和本地工作流保持可用。

机型档案代表设备识别和参数范围已进入源码，不等同于所有固件、镜头、线材和主机组合均已
完成硬件验收。重要拍摄请保留相机存储卡。

## 交付包与签名状态

- `ZENCHE-1.3.1-android.apk`：Android 调试证书签名 APK。
- `ZENCHE-1.3.1-HarmonyOS.hap`：本地 HAP；无 signing profile 时为未签名验证包。
- `ZENCHE-1.3.1-ios-unsigned.ipa`：iOS / iPadOS 未签名验证包，必须重新签名。
- `ZENCHE-1.3.1-macOS-arm64.dmg`：Apple Silicon、ad-hoc 签名、未公证。
- `ZENCHE-1.3.1-Windows-x64-Setup.exe`：x64 NSIS 安装器，未使用商业代码签名证书。
- `ZENCHE-1.3.1-Windows-x64.zip`：x64 便携包，需完整解压并保留 `libusb-1.0.dll`。

每个交付包都附带同名 `.sha256` 文件。校验示例：

```sh
shasum -a 256 -c ZENCHE-1.3.1-macOS-arm64.dmg.sha256
```

Windows PowerShell：

```powershell
Get-FileHash .\\ZENCHE-1.3.1-Windows-x64-Setup.exe -Algorithm SHA256
```

## 已知限制

- Android SDK 源列表可能出现远程 manifest/TLS 警告，但本地缓存可完成构建。
- HarmonyOS 没有 signing profile 时只能生成未签名 HAP，不能视为正式可安装包。
- iOS IPA 未签名；macOS DMG 未公证；Windows 包未使用商业签名。
- Windows 本次在 macOS 交叉构建，尚未替代真实 Windows 主机完成安装、升级、卸载、驱动
  和 SmartScreen 验收。
- 当前构建机访问 `https://zenche.top` 曾遇到 `LibreSSL SSL_ERROR_SYSCALL`；代码中的
  HTTPS 地址保持正确，官网证书、TLS 和公网可达性仍需由官网侧确认。
- Sony / Canon 适配仍需要更多不同固件、镜头和拍摄模式的真机验证。

## 升级指南

1. 从本 Release 下载对应平台包和 `.sha256` 文件并完成校验。
2. 安装前保留相机存储卡，并关闭可能占用 PTP 的其他软件。
3. 首次进入 AI 工具时复制设备 ID；已有激活密钥继续在当前设备上验证，旧 AI 服务器配置
   不需要迁移。
4. 若没有兑换码，使用应用内爱发电入口购买，再回到 `zenche.top` 完成设备绑定兑换。
5. 遇到问题时提供平台、相机型号、固件、镜头、线材、复现步骤和脱敏诊断日志；不要在
   Issue 或群组中公开激活密钥、设备敏感信息或任何 API Key。
