# 帧澈 ZENCHE v1.5.3（本地开发候选）

> 候选日期：2026-08-04（Asia/Shanghai）
> 版本：`1.5.3 / build 28`
> 分支：`agent/1.5.3-ui`
> 状态：尚未推送、打标签、创建 GitHub Release 或部署生产

## 本轮重点

- 全屏监看采用影像优先的专业 HUD：顶部连接/曝光遥测、焦点十字、左右工具与录制操作、实际 RGB 数据示波器、明确的静音音频基线，以及底部参数托盘。
- 拍摄与参数页采用设备摘要、自适应参数卡和常驻拍摄操作区，让连接方式、输出格式、曝光参数与文件库数量保持可见。
- 编辑器采用媒体池、中央预览、工具检查器和分析示波器协作布局；现有专业显影、AI 工具、蒙版、色轮、曲线和高质量副本保存链路均保留。
- 五端统一深色工作台颜色角色：ZENCHE 蓝用于主操作和选中状态，暖金只用于活动参数读数，红色只用于录制、停止录制和危险操作。

## 数据与兼容性边界

- 新界面不创建第二套业务状态：相机连接、取景、快门、AF、外录、图库与编辑操作继续走 1.5.2 的既有服务和动作。
- RGB 示波器只显示实时画面直方图或本地编辑分析值；没有音频源时显示静音基线，不模拟音量。
- 编辑调整继续写入高质量新副本，不覆盖原文件；设备码恢复、AI 次数、激活码、USB/PTP 与无线传输协议没有改变。
- 参考图只用于信息层级、密度与布局方向，不复制第三方商标、品牌名称或专有图标。

## 审查收敛

- 恢复 iOS 拍摄页的会话配置与开始/结束入口；五端原有拍摄、监看、编辑、AI、传输和设备码恢复入口均保留。
- 所有新增 HUD、设备摘要、底部读数、工具轨和参数托盘都按真实连接状态显示；无可用画面或相机数据时统一降级为 `—`、`OFFLINE` 或无源提示，不显示初始化默认值。
- Android 编辑器的色轮、曲线和蒙版快捷入口会展开并滚动到实际控件，AI 入口进入现有 AI 工作区，不再以提示消息代替操作。
- Windows 编辑工作台增加窄窗断点：窗口宽度低于 1120 时收起媒体栏并压缩工具栏，保留中央预览可用宽度。
- 新增界面标签、空态与辅助功能提示已补齐简体中文、英文、日文资源。
