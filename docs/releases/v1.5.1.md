# 帧澈 ZENCHE v1.5.1

帧澈 ZENCHE v1.5.1 是五端同步的 AI 修图可靠性与蒙版修复版本，版本号为
`1.5.1`，原生构建号为 `26`。本版本继续保留升级、签名、偏好设置、设备码和
历史素材库所需的 `NikonLink` 与 `com.tauber.nikonlink` 内部标识。

## 版本亮点

- 修复 AI 修图无法选择或确认原图的问题：进入修图后立即显示当前所选原图，切换照片会清除旧 AI 结果，避免把上一张照片的结果误当成当前输入。
- 新增“智能移除”预设：支持去路人并自然补全背景，以及去除摄影器材、工作人员、反光、杂物等穿帮元素。
- 重做蒙版可视化：智能蒙版和画笔蒙版都从真实蒙版像素生成蓝色 Alpha 覆盖，不再用近似笔迹代替蒙版范围。
- 修复橡皮工具显示白色的问题：橡皮现在直接减少蒙版覆盖，蓝色区域随擦除实时消失。
- 修复蒙版删除、显示、反转和局部调整合成；曝光、对比度、色温、色调、饱和度、高光、阴影、清晰度和细节只作用于对应蒙版范围。
- Android 只为既有 AI 代理地址开放受限明文网络例外，其他域名继续禁止明文流量。
- iOS / iPadOS、Android 和 HarmonyOS 的 AI 请求等待时间延长至 300 秒，并优先展示服务端错误详情，减少长时间任务被客户端提前判定失败。

## 五端变化

- **iOS / iPadOS**：AI 修图页显示当前原图；选图后清除旧结果；增加智能移除；请求超时提升至 300 秒并解析服务端错误；Core Image 使用真实蒙版生成蓝色覆盖，局部参数通过蒙版合成。
- **Android**：修复 AI 修图原图预览和移动端请求失败；为既有代理增加域名级网络安全配置；增加智能移除；蒙版视图按真实蒙版 Alpha 绘制蓝色覆盖，橡皮不再绘制白色。
- **HarmonyOS**：AI 修图页显示当前原图并清除旧结果；增加智能移除、300 秒请求等待和服务端错误详情；ArkUI 预览使用真实 PixelMap 蓝色蒙版覆盖，并在绘制时刷新。
- **macOS**：增加原图预览与智能移除；Core Image 蒙版改为真实蓝色覆盖，并保持各局部参数仅在蒙版范围合成。
- **Windows**：AI 工具获得独立原图选择弹窗；预览在生成前显示当前原图；增加智能移除；WPF 使用真实 Pbgra32 蓝色蒙版位图替代蓝白笔迹近似显示。

## 相机与兼容性变化

本版本不改变现有 20 款 Nikon、12 款 Sony α 和 10 款 Canon EOS R 相机档案，
也不改变 USB/PTP、PTP/IP、FTP、HTTP、WebDAV、BLE 遥控及外录兼容范围。
AI 修图仍要求服务器可用、有效激活码与剩余次数；去路人和去穿帮结果会受输入图像、
提示词和上游模型能力影响。

## 包与签名状态

- Android APK 复用现有调试证书签名，证书身份与上一正式版一致，可用于侧载验证，但不是商店发布签名。
- HarmonyOS HAP 未配置既有开发者签名与 Profile，构建产物不能作为已签名官方升级包，真机安装前需要原签名材料重新签名。
- iOS / iPadOS IPA 为未签名验证包；当前环境缺少既有分发证书和 provisioning profile，必须用原发布身份重新签名后才能安装升级。
- macOS DMG 内应用采用与上一版相同的 ad-hoc 签名方式并执行深度校验；当前环境没有既有 Developer ID 与公证凭据。
- Windows Setup 与便携 ZIP 未使用 Authenticode 商业代码签名证书，与上一版发布状态一致；SmartScreen 可能显示警告。

## 已知限制

- 当前构建环境缺少 iOS / iPadOS、HarmonyOS、macOS 和 Windows 的正式发布签名材料；附件会准确标注其验证包或社区构建属性，不应误认为商店、公证或 Authenticode 签名包。
- AI 服务耗时仍受网络质量、代理状态、图像大小和上游模型排队影响；300 秒等待结束后需要重试，失败任务不会生成本地结果。
- 智能蒙版依据设备端像素分析近似生成，复杂边缘、半透明物体、反光和低对比区域仍可能需要画笔与橡皮手动修正。
- 去路人和去穿帮是提示词驱动的云端生成式编辑，建议先备份重要原片并检查补全区域，正式交付前不要只依赖自动结果。
- 五端相机真机矩阵仍在扩大；本版本不改变机身控制能力，重要拍摄必须保留相机存储卡作为独立备份。

## 升级说明

升级前建议备份 ZENCHE 文件库和会话目录。Android 可在签名身份一致时侧载覆盖；
Windows Setup 可覆盖安装，便携版应完整解压并保持 `libusb-1.0.dll` 与 SDK 目录结构。
iOS / iPadOS、HarmonyOS 和 macOS 必须使用既有发布身份重新签名，才能保持升级连续性。
首次打开 AI 修图后，建议选择一张测试照片确认原图预览、智能移除、蓝色蒙版、橡皮和
局部参数范围均符合预期，再处理重要素材。
