# 帧澈 ZENCHE v1.1.0

帧澈 ZENCHE 1.1.0 将联机拍摄从单张控制扩展为可组织、可校验、可监看的完整原生工作流，五个原生目标保持一致。

## 版本亮点

- 新增间隔拍摄、曝光包围、焦点包围和 B 门计时，支持进度显示与取消。
- 新增拍摄会话、项目目录、命名模板、RAW + JPEG 同名配对、XMP 评级、双目标备份和 SHA-256 清单。
- 新增 RGB 直方图、亮度波形、矢量示波器、峰值对焦和假色；所有效果仅用于本地监看，不修改原片。
- 新增 Mirror酱优先更新检查、可选 CDK、平台安全存储与 GitHub 自动降级；签名应用仅接收完整安装包。

## 平台变化

- macOS、Android、HarmonyOS 和 Windows 通过 Nikon USB/PTP 执行相机任务；焦点包围依赖机身实时取景和镜头支持。
- iOS / iPadOS 使用 AVFoundation 支持的本机或外接视频设备执行对应任务，并从视频帧生成专业监看数据。
- 五端文件导入与拍摄保存统一经过会话工作流；RAW 与 JPEG 按原始文件名主干共用基础命名。
- 五端设置页新增 Mirror酱 CDK 与来源入口；Apple 平台使用钥匙串、Android 使用 Keystore、Windows 使用 DPAPI，HarmonyOS 使用应用私有设置。

## 相机与兼容性

- 相机档案仍覆盖 17 款 Nikon EXPEED 6 / 7 机型。
- 实际可写参数取决于机身固件、镜头、曝光模式、USB 接口占用和平台权限。
- 焦点包围要求机身允许实时取景期间执行手动焦点驱动；不支持的组合会返回明确错误。

## 安装包与签名

- `ZENCHE-1.1.0-macOS-arm64.dmg`：Apple Silicon，ad-hoc 签名，未进行 Apple 公证。
- `ZENCHE-1.1.0-android.apk`：调试证书签名，需要允许侧载。
- `ZENCHE-1.1.0-HarmonyOS.hap`：本地未签名验证包，真机安装前需要匹配的开发者签名与 Profile。
- `ZENCHE-1.1.0-ios-unsigned.ipa`：未签名验证包，必须使用有效证书和描述文件重新签名。
- `ZENCHE-1.1.0-Windows-x64-Setup.exe`：x64 NSIS 安装程序，未使用商业代码签名证书。
- `ZENCHE-1.1.0-Windows-x64.zip`：x64 便携包，需完整解压并保留 `libusb-1.0.dll`。

## 验证

- macOS Swift 类型检查与应用打包。
- iOS / iPadOS 模拟器编译与无签名设备包构建。
- Android Java 编译、资源处理与 APK 组装。
- HarmonyOS ArkTS 编译与 HAP 组装。
- Windows WPF 跨主机编译、NSIS 安装程序与便携 ZIP 打包。
- Node.js 回归测试、版本一致性检查和包校验文件回验。

## 已知限制

- 自动任务不会替代机内存储卡；重要拍摄必须保留相机内独立副本。
- Mirror酱资源标识 `ZENCHE` 仍需服务方完成注册与平台包映射；注册前客户端会自动回退 GitHub，不影响更新检查。
- B 门、曝光补偿和焦点驱动可能因相机当前模式而被锁定。
- 专业监看分析使用本地预览帧，不代表相机内部 RAW 数据。
- iOS / iPadOS 普通应用无法直接获得 Nikon 通用 USB/PTP 厂商控制能力。

## 升级指引

- 可直接覆盖安装 1.0.0；内部应用标识保持不变，原有偏好与本地文件库继续使用。
- 首次使用拍摄会话前，请确认项目名、命名模板、评级和双目标备份设置。
- Windows 用户若更换 USB 驱动，请先阅读 `docs/WINDOWS_BUILD.md`，避免影响 Nikon 官方软件。

## SHA-256 校验

下载安装包及同名 `.sha256` 文件后执行：

```sh
shasum -a 256 -c ZENCHE-1.1.0-macOS-arm64.dmg.sha256
```

Windows PowerShell：

```powershell
Get-FileHash .\ZENCHE-1.1.0-Windows-x64-Setup.exe -Algorithm SHA256
```
