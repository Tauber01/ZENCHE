# 帧澈 ZENCHE v1.4.1

帧澈 ZENCHE v1.4.1 是一次面向五端原生监看工作区的小版本更新，版本号为
`1.4.1`，原生构建号为 `24`。本版本继续保留升级、签名和历史配置所需的
`NikonLink` 与 `com.tauber.nikonlink` 内部标识。

## 版本亮点

- 监看页左侧改为 RGB 三色波形，右侧新增音频波形卡；相机音频传输尚未接入时明确显示“无音频源 · 静音基线”，不伪造电平数据。
- 监看页支持直接调节帧率、快门角度、ISO，以及现有平台可写的相关参数。
- 点击监看预览画面会显示焦点标记并请求原生对焦；PTP 平台按点击位置映射焦点步进，设备不支持时如实提示。
- 移除监看镜头读数和“曝光”工具入口。
- Android 将录制键移动到 RGB 波形与音频波形之间，并删除监看预览右上角的全屏按钮。

## 五端变化

- **iOS / iPadOS**：原生监看布局加入 RGB、音频波形和点按焦点反馈；保留系统相机与 UVC 能力边界，产出未签名 IPA。
- **Android**：USB/PTP 监看工作区按新布局排列录制键与两张波形卡，移除全屏入口，支持点按焦点和监看参数调节。
- **HarmonyOS**：ArkUI 监看页同步波形、参数调节、焦点标记和点按焦点行为。
- **macOS**：SwiftUI/AppKit 监看控制台同步新波形卡、可调参数和点按对焦反馈。
- **Windows**：WPF 监看面板同步新波形卡、参数读数、点按焦点和录制布局；同时生成安装版与便携版。

## 相机兼容性

本版本沿用现有 Nikon / Sony / Canon 相机档案与 USB/PTP 能力。参数是否能够写入机身，
取决于相机型号、固件、镜头、当前拍摄模式以及系统权限；监看波形和 LUT 等本地显示
处理不会修改原片或写入相机视频设置。点按对焦需要实时取景和机身对焦能力，未开启
实时取景或不支持该能力时客户端会显示失败/提示。五端相机真机覆盖仍在扩大中。

## 签名状态与已知限制

- macOS：arm64 ad-hoc 签名，未公证。
- Android：使用调试证书签名，侧载安装前请确认设备允许安装来源。
- HarmonyOS：未提供面向最终用户的开发者签名/Profile，真机安装前需重新签名。
- iOS / iPadOS：未签名 IPA，必须使用有效的 Apple 开发者证书和 provisioning profile 重新签名，不能直接安装。
- Windows：安装程序和便携包未使用商业代码签名证书，Windows SmartScreen 可能显示警告。
- 音频波形当前为静音基线，因为相机音频传输管线尚未接入；这不是实时音量测量结果。

## 升级说明

请从下方 GitHub Release 下载目标平台包及同名校验文件。升级前建议保留相机机内存储卡
和现有本地素材库；Windows 安装版可直接覆盖安装，便携版请完整解压并保持
`libusb-1.0.dll` 与程序位于同一目录。iOS、HarmonyOS 用户需要按各自平台重新签名。
