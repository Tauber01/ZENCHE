## 候选目标

本候选为 iOS/iPadOS、Android、HarmonyOS、macOS 与 Windows 增加统一的“下载到本地”能力。用户可以把以下 ZENCHE 文件另存到自己选择的位置：

- 联机拍摄和外录产生的照片或视频；
- 从相机存储卡下载到 ZENCHE 文件库的文件；
- AI 修图与 AI 生图结果；
- 专业显影和其他编辑流程生成的新副本。

五端文件库均提供统一入口；支持应用内预览的页面也提供快捷入口，AI 与专业编辑工作区提供直达入口。移动端已有的“保存到系统相册”继续独立保留，不与本地文件保存器合并。

## 数据与错误语义

- 导出只创建副本，不移动、删除或原位修改 ZENCHE 文件库源文件。
- AI 与编辑工作区的直达流程先生成新的文件库副本，再打开系统保存器。macOS 与 Windows 的 AI 修图改为始终创建新文件，不再覆盖当前原图。
- iOS/iPadOS 使用系统文档导出器，Android 使用 Storage Access Framework，HarmonyOS 使用 DocumentViewPicker，macOS 使用 NSSavePanel，Windows 使用 SaveFileDialog。保存位置、文件名与同名覆盖确认由操作系统负责。
- 用户取消是中性结果，不显示成功，也不显示错误。只有完整复制、同步落盘并通过目标大小校验后才报告成功。
- 失败会清理本次临时文件；对于 Android/HarmonyOS 文档提供器目标，会尽力删除不完整目标。由于跨提供器通常不支持事务重命名，不能把移动端文档提供器写入描述为严格原子提交。
- 桌面端在目标同目录写入受限命名的临时文件，完成同步和大小校验后再替换或同卷移动。macOS 使用文件资源标识，Windows 使用卷序列号与文件索引，并在复制前和发布前复核，拒绝符号链接、Finder alias、junction 或 hardlink 指回源文件；大文件复制在后台执行，避免阻塞界面。
- Android 在系统保存器期间保存库内相对路径，Activity 被系统重建后仍可恢复待导出的源文件；写入前以设备号和 inode 拒绝目标指回源文件，完成 `fsync` 后读取目标文件实际大小再报告成功。HarmonyOS 的复制、同步和大小校验通过 TaskPool 执行。
- 导出保持原文件字节和扩展名，不重新编码 JPEG、RAW 或视频。五端文件库统一识别 JPG/JPEG、HEIF/HEIC、PNG、TIF/TIFF、NEF/NRW、ARW、CR2/CR3、MOV/MP4/M4V 与 AVI；能否直接预览仍取决于平台解码能力。

## 相机与兼容性

- 本候选不增加或删除相机档案，也不改变 USB/PTP、PTP/IP、实时监看、拍摄或外录协议。
- 现有 Nikon、Sony、Canon 注册表与各平台能力边界保持不变；相机注册表不等同于全部机型已经完成实机验证。
- “下载到本地”覆盖已经进入 ZENCHE 文件库的受支持 JPEG、RAW 与视频文件。系统保存器、文档提供器、权限、同名覆盖、无空间和大文件行为仍需各平台实测。
