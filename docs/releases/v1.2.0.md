# 帧澈 ZENCHE v1.2.0

帧澈 ZENCHE 1.2.0 聚焦原生文件组织、移动端全屏控制和非破坏性修图工作流。iOS / iPadOS、Android、HarmonyOS、macOS 与 Windows 五个目标保持统一能力，同时继续使用各平台原生控件与交互规范。

## 版本亮点

- 将“分支”提升为文件页面的重要工作区，支持用户建立任意层级的项目、客户或拍摄日分支。
- 支持把本地媒体拖拽到其他分支或“未分类”，组织关系会持久保存，但不会重命名、复制或移动底层原文件。
- 支持删除分支；删除后媒体安全返回“未分类”，照片在任意分支中继续显示缩略图。
- 手机端分支树改为默认折叠抽屉，平板、展开态折叠屏与桌面端继续常驻显示完整树状结构。
- 五端新增“专业显影”编辑页面，提供光线、色彩、细节、效果与几何五组参数、五种透明预设、原图对比、全部重置和高质量副本导出。
- 移动端全屏调参控件进一步紧凑化，同时扩大展开、收起和增减操作的有效判定面积；新增可展开的二级参数区。

## 平台变化

- iOS / iPadOS：使用 SwiftUI 与 Core Image 实现曝光、白平衡、高光阴影、自然饱和度、局部对比、锐化、降噪、暗角、旋转翻转和比例裁切；手机分支工作区使用原生折叠抽屉。
- Android：使用原生 Views 实现分组调节、预设、前后对比和像素域显影处理；支持触摸拖拽归类、分支删除和移动端抽屉。
- HarmonyOS：使用 ArkUI 与 PixelMap 实现统一参数、像素处理、翻转旋转、中心比例裁切和 JPEG 副本导出；分支数据继续保存于应用私有存储。
- macOS：使用 SwiftUI、AppKit 与 Core Image 提供以大预览为中心的桌面专业显影布局，并保留原生树状分支和拖拽操作。
- Windows：使用 WPF 动态生成可展开调节组，像素域管线与其他平台保持一致；树状分支支持拖放、删除和缩略图。

## 相机与兼容性

- 相机档案仍覆盖 17 款 Nikon EXPEED 6 / 7 机型，本版本没有移除或缩减现有机型支持。
- 相机参数的实际可写范围仍取决于机身固件、镜头、曝光模式、USB 接口占用和平台权限。
- 二级全屏参数只显示当前平台与连接设备真正支持的控制项，不会伪造不可写参数。
- iOS / iPadOS 继续受系统公开 API 限制，普通应用无法直接获得 Nikon 通用厂商 USB/PTP 控制能力。

## 安装包与签名

- `ZENCHE-1.2.0-macOS-arm64.dmg`：Apple Silicon，ad-hoc 签名，未进行 Apple 公证。
- `ZENCHE-1.2.0-android.apk`：调试证书签名，需要允许侧载。
- `ZENCHE-1.2.0-HarmonyOS.hap`：本地未签名验证包，真机安装前需要匹配的开发者签名与 Profile。
- `ZENCHE-1.2.0-ios-unsigned.ipa`：未签名验证包，必须使用有效证书和描述文件重新签名。
- `ZENCHE-1.2.0-Windows-x64-Setup.exe`：x64 NSIS 安装程序，未使用商业代码签名证书。
- `ZENCHE-1.2.0-Windows-x64.zip`：x64 便携包，需完整解压并保留 `libusb-1.0.dll`。

## 验证

- Node.js 原生能力、版本一致性、本地化、分支文件库、图像编辑器与已知问题回归测试。
- iOS / iPadOS 无签名设备包构建与 Xcode 编译。
- Android Java 编译、资源处理与 APK 组装。
- HarmonyOS ArkTS 编译、PixelMap API 检查与 HAP 组装。
- macOS Swift 类型检查、应用打包、ad-hoc 签名与 DMG 生成。
- Windows WPF 跨主机编译、NSIS 安装程序和便携 ZIP 生成。
- 所有本地交付文件均生成并回验同名 SHA-256 校验文件。

## 已知限制

- 专业显影不会覆盖原片；当前导出为质量 95 的 JPEG 副本。
- 可编辑文件取决于平台能够稳定解码的光栅格式。暂不把无法可靠解码的 RAW 或视频显示在编辑器选择器中；专业显影也不宣称复制 Adobe 品牌、专有图标或界面外观。
- Android 调试证书、HarmonyOS 未签名包、iOS 未签名包、macOS ad-hoc 签名和 Windows 未签名安装程序均不等同于商店正式签名。
- 拖拽分支只改变帧澈内部分类，不会改变原文件在磁盘、系统照片库或相机存储卡中的位置。
- 重要拍摄仍应保留相机内存储卡作为独立副本。

## 升级指引

- 可直接覆盖安装 1.1.0；内部应用标识保持不变，原有偏好、接收文件和拍摄会话继续使用。
- 升级后本地媒体默认显示在“未分类”；可在分支工作区建立层级并拖拽整理。
- 删除分支前会显示破坏性确认，删除结构不会删除底层媒体。
- Windows 用户若更换 USB 驱动，请先阅读 `docs/WINDOWS_BUILD.md`，避免影响 Nikon 官方软件。

## SHA-256 校验

下载安装包及同名 `.sha256` 文件后执行：

```sh
shasum -a 256 -c ZENCHE-1.2.0-macOS-arm64.dmg.sha256
```

Windows PowerShell：

```powershell
Get-FileHash .\ZENCHE-1.2.0-Windows-x64-Setup.exe -Algorithm SHA256
```
