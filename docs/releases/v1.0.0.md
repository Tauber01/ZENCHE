# 帧澈 ZENCHE v1.0.0

帧澈 ZENCHE 1.0.0 是首个稳定版，面向 Nikon 相机控制、实时监看、影像接收与本地管理工作流。公开品牌统一为“帧澈 ZENCHE”，内部仍保留兼容既有安装升级所需的 `NikonLink` 标识。

## 版本亮点

- 五个原生客户端统一提供简体中文、English、日本語界面。
- 原生相机工作区覆盖照片拍摄、实时取景、视频录制、曝光/对焦/白平衡控制、斑马纹、LUT 监看和本地图库。
- macOS、Android、HarmonyOS 与 Windows 内置 17 款 Nikon EXPEED 6 / 7 机型档案。
- 五个平台均支持 FTP、HTTP PUT/POST 与 WebDAV 前台影像收件箱。
- 新增版本公告、防诈骗提醒、更新入口和赞助入口。

## 平台变化

- **macOS**：原生 SwiftUI/AppKit 客户端，内置 `gphoto2` 与运行依赖；提供 USB/PTP 连接、监看、拍摄和本地照片管理。
- **Android**：原生 Android Views 客户端，使用 USB Host/PTP 直连；针对 Android 13–16 的 USB 授权与 OEM USB 传输差异进行了恢复处理。
- **HarmonyOS**：原生 Stage/ArkUI 客户端，提供分块 USB/PTP 传输、拍摄、监看和本地收件箱。
- **Windows**：原生 Windows 11 WPF 客户端，使用 libusb 直连；同时提供安装程序和便携包。
- **iOS / iPadOS**：原生 SwiftUI/AVFoundation 客户端，支持系统相机、兼容的外接 UVC 视频设备、影像接收和系统相册导出。

## 支持相机与兼容性

内置 Nikon Z9、Z8、Z f、Z6III、Z50II、Z5II、ZR、Z7、Z6、Z50、D780、D6、Z5、Z7II、Z6II、Z fc、Z30 共 17 款机型档案。USB/PTP 功能会受到相机固件、拍摄模式、菜单锁定、USB 线材以及其他相机软件占用情况影响；连接前请退出 NX Tether、Camera Control Pro、“照片”和“图像捕捉”等可能占用设备的程序。

## 安装包与签名状态

- `ZENCHE-1.0.0-macOS-arm64.dmg`：Apple Silicon，ad-hoc 签名，未进行 Apple 公证。
- `ZENCHE-1.0.0-android.apk`：调试证书签名，需要允许侧载。
- `ZENCHE-1.0.0-HarmonyOS.hap`：安装到真机前需要与设备匹配的开发者签名和 Profile。
- `ZENCHE-1.0.0-Windows-x64-Setup.exe`：x64 安装程序，未使用商业代码签名证书。
- `ZENCHE-1.0.0-Windows-x64.zip`：x64 便携包，必须完整解压并保留 `libusb-1.0.dll`。
- `ZENCHE-1.0.0-ios-unsigned.ipa`：未签名验证产物，必须使用有效证书和描述文件重新签名后安装。

每个安装包均提供同名 `.sha256` 文件。

## 验证

- 自动化测试覆盖 17 款相机档案对齐、Android USB 过滤、跨平台公告、三语本地化和版本/构建号一致性。
- 构建流程验证 macOS DMG、Android APK、iOS 未签名 IPA、HarmonyOS HAP、Windows Setup EXE 与便携 ZIP。
- 对产物执行 SHA-256 校验；macOS 应用执行深度代码签名验证。

## 已知限制

- 社区构建没有 Apple 公证、Android 正式发布证书或 Windows 商业代码签名证书，首次启动时系统可能显示安全提示。
- HarmonyOS 与 iOS 产物受开发者签名限制，不能保证下载后直接安装。
- Nikon USB/PTP 的参数可写性取决于机身模式和固件；部分菜单、视频规格和编码选项仅作为本地监看参考，不能覆盖相机未开放的能力。
- iOS / iPadOS 不提供 Nikon USB/PTP 控制，使用系统相机或兼容的外接 UVC 视频设备。

## 升级说明

可直接覆盖安装旧版本。为保证升级、偏好设置和签名兼容，应用内部包名及部分工程标识仍使用 `NikonLink` / `com.tauber.nikonlink`；请勿手工删除这些偏好数据。Windows 建议使用 Setup EXE 原位升级；便携版用户应完整替换整个目录。

## SHA-256 验证

下载目标安装包及对应 `.sha256` 文件后进行校验：

```bash
shasum -a 256 -c ZENCHE-1.0.0-macOS-arm64.dmg.sha256
```

Windows PowerShell：

```powershell
Get-FileHash .\ZENCHE-1.0.0-Windows-x64-Setup.exe -Algorithm SHA256
```

输出摘要应与同名 `.sha256` 文件中的 64 位十六进制值完全一致。
