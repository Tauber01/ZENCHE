# 帧澈 ZENCHE 1.5.14 发布说明

> 发布日期：2026-08-20（Asia/Shanghai）
> 版本：`1.5.14 / build 41`
> 发布阶段：源码封板中；安装包、摘要与公开发布证据将在最终重建后回填

## 本次更新

1.5.14 聚焦三件摄影现场最容易打断工作的事：相机连不上或连接中断、电脑里的
照片和视频难以快速进入 ZENCHE，以及文件库层级过深。本版同时补充 Sony ZV-E10
及同代机型的识别与兼容配置，并将五个平台的文件管理统一为“所有文件”优先。

### 相机连接与断线恢复

- 修复五端 Wi‑Fi/PTP‑IP 在心跳、命令、事件和自动重连交错时出现的假断线、响应
  串读与旧会话复活。心跳改为 event 通道标准 Probe Request/Response，常驻 reader
  同时响应相机主动探测并排空事件。
- Apple、HarmonyOS 与 Windows 将完整 command transaction 串行化；Android 保留
  实例同步边界。响应 transaction ID、GetDeviceInfo 数据集以及 data-out 分帧均按
  PTP 约定收紧。
- 连接、重连、取消和断开由会话代际隔离。手动取消后，旧握手、旧 writer 或旧相机
  回调不能再覆盖新状态；command-only 传输失败也会进入同一恢复流程。
- Windows 单轮重连有明确上限，只有在厂商识别、取景、参数与监看恢复后才恢复拍摄
  操作；外部 USB 相机命令使用“有活动即续期”的空闲超时并终止整个进程组，避免
  辅助程序静默挂死。
- 五端顶层均可直接进入 Wi‑Fi/PTP‑IP，失败后可重试，连接中可取消，重连中可停止；
  当前模式、IP、端口和恢复提示与真实状态保持一致。

### Sony ZV-E10 与同代机型

- 五端相机档案从 46 款扩展到 50 款，其中 Sony 从 12 款扩展到 16 款。
- 新增 Sony ZV-E10、A6100、A6400、A6600；同时识别 A6100A 与 A6400A 名称别名。
- iOS 不再把 Sony 误送到 Nikon 兼容桥；macOS 在官方 SDK 明确不支持时可以回退到
  gphoto2 兼容路径。
- 这里的“支持”指机型识别、能力档案和可用传输路径。Sony 当前公开的 Camera Remote
  SDK 支持表未列出上述旧机型，因此完整遥控、实时取景、参数、传输与重连能力仍须
  使用对应真机逐项验证，不能仅凭静态档案视为官方 SDK 全功能支持。

### macOS / Windows 一键导入

- 桌面端新增“导入照片与视频”主操作，可一次选择多个文件，也可取消正在执行的批次。
- 采用流式读写、同目录临时文件、落盘同步、字节数复核与原子发布，避免大文件整块
  占用内存或把半成品暴露给文件库。
- 支持 RAW+JPEG 同目录配对、重复文件跳过、双备份、XMP 与 SHA-256 校验清单。
- 批次逐项报告成功、跳过、失败或取消；某一项失败不会撤销已经安全提交的其他文件。

### 更简单的五端文件库

- iOS/iPadOS、Android、HarmonyOS、macOS 和 Windows 均以“所有文件”为默认首屏，
  提供搜索、照片/视频筛选和最近/名称排序。
- 项目分类与来源/工具默认收起；分类只写入持久化元数据，不移动原文件。
- macOS 使用懒加载网格和 128 项缩略图缓存；Windows 使用回收虚拟化、后台缩略图
  解码和 128 项缓存，降低大型文件库的初次加载与滚动压力。
- 桌面删除改用系统废纸篓/回收站。成功后才清除项目归属，并按文件真实路径同步其
  历史会话备份、校验清单与 XMP；同 stem 的 RAW/JPEG 兄弟仍存在时保留共享 XMP。

## 安装与升级

- 升级前建议先备份正在使用的 ZENCHE 工作目录，完成中的导入或相机传输应先等待结束。
- Android APK 使用项目连续的 v2 Debug 证书；已安装版本只有证书一致时才能原位升级。
- iOS/iPadOS IPA 和 HarmonyOS HAP 未签名，只适用于具备自行签名/安装条件的测试环境。
- macOS DMG 内应用为 Apple Silicon arm64、ad-hoc 签名且未公证；首次运行可能需要按
  系统安全提示手动确认。
- Windows 提供 x64 安装版和便携版，均无 Authenticode；安装版的启动 stub 为既有
  PE32 i386 NSIS 引导器，但实际载荷与主程序为 x64，并写入 64 位安装目录和注册表。
- 如升级后无法连接，请先确认电脑/手机已加入相机 Wi‑Fi，相机已启用 PTP/IP 或电脑
  遥控模式，并核对 IP 与端口；随后使用“重试”，或停止重连后重新建立会话。

## 已知限制

- 尚未使用真实 Nikon、Sony 或 Canon 相机完成主动/被动 Probe、并发实时取景、相机
  参数、断网退避重连、取消/重试和大文件导入的完整验收。
- 尚未完成移动端真实设备安装、Windows 实机启动/驱动/SmartScreen、macOS Gatekeeper
  与可信签名/公证验收。编译、静态契约和容器校验不能替代这些实机门禁。
- 当前单个 PTP/IP 包保留 64 MiB 防御性上限；超过约 64 MiB 的对象依赖相机拆分为
  多个 Data/EndData 包，单一超大 EndData responder 仍不兼容。
- 5 秒 Probe 周期与 3 秒超时是 ZENCHE 的恢复策略，并非 CIPA 规定值；不同相机与
  网络环境的最优阈值仍需实机数据校准。
